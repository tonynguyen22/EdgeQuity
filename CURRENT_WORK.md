## Working mental model

Edgequity is a static-first React screener:

1. Build scripts generate normalized stock JSON and a manifest under `public/data/edgequity`.
2. Browser loads manifest and stock JSON directly from static files.
3. Main table filters/sorts local records only.
4. Selecting a ticker opens detail view.
5. Detail view calls a Vercel API route for cached Finnhub profile, quote, and metrics.
6. Charts combine embedded SEC statement periods with selected Finnhub ratio series.

## NVDA Debug Update - 2026-05-31

User reported NVDA data issues. Root causes found and fixed:

- SEC annual facts for NVDA include restated split-adjusted EPS/share rows with the same period end but later filing/fy metadata. The old picker bucketed non-calendar annual rows by SEC `fy`, so FY2023/FY2024 could keep pre-split or wrong-year rows. Fixed `pickAnnualUsdValues` to group annual facts by fiscal period end year and prefer restated/frame rows when period end is the same.
- SEC balance sheet facts are instant facts without `start` dates. The old quarterly extractor required 70-120 day duration, so NVDA quarterly balance sheets were empty. Added `pickQuarterlyInstantUsdRows` and routed balance sheet quarterly extraction through it.
- NVDA quarter label offset was correctly needed for SEC calendar quarter labels, but it was also applied to annual labels. Fixed annual chart labels to stay on reported fiscal years while keeping quarter offset.
- Refreshed `public/data/edgequity/stocks/NVDA.json` with the fixed SEC normalizer. ## Q4 Derivation Fix - 2026-06-01

User reported NVDA missing Q4 data in quarterly income statements and cash flows.

Root cause: SEC does not file a separate 10-Q for Q4. Q4 data is embedded in the 10-K annual report. The quarterly fact picker (`pickQuarterlyUsdRows`) only picks rows with `fp=Q1|Q2|Q3|Q4` and 70-120 day duration. Since Q4 is never filed as a standalone 10-Q, all companies were systematically missing Q4 for duration-based facts (income statement, cash flow). Balance sheet was unaffected because it uses instant facts.

Fix: Added `deriveQ4Rows` in `scripts/edgequity/sec-normalized.ts`. For each annual period that has exactly 3 matching quarters (Q1+Q2+Q3, matched by date range not fiscal year label), derives Q4 = Annual − Q1 − Q2 − Q3 for additive metrics: revenue, grossProfit, operatingIncome, netIncome, ebitda (income statement) and operatingCashFlow, capitalExpenditure (cash flow). FreeCashFlow for Q4 is then computed by the existing `finishCashFlows` step.

Cash flow Q4 is NOT derived for NVDA because SEC quarterly cash flow data only has Q1 (cumulative YTD reporting means Q2/Q3 standalone aren't available). This is correct behavior — derivation requires all 3 prior quarters.
